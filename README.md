# CodeArena - Online Judge Platform 🚀

CodeArena is a full-stack competitive programming platform where users can solve coding problems, execute code securely, submit solutions, and receive automatic verdicts.

## Features

### Authentication
- User registration and login
- JWT based authentication
- Role based access (User/Admin)

### Problem Platform
- Browse coding problems
- View problem descriptions
- Difficulty levels and tags
- Problem solving interface

### Online Compiler
- Monaco code editor
- Multi-language support:
  - C++
  - C
  - Java
  - Python
  - JavaScript

### Code Execution & Judging
- Docker based isolated code execution
- Custom input testing
- Automatic testcase evaluation
- Verdict generation:
  - Accepted
  - Wrong Answer
  - Compilation Error
  - Runtime Error
  - Time Limit Exceeded

### User Dashboard
- Problems solved
- Submission statistics
- Recent submissions

### Additional Modules
- Practice Arena
- Leaderboard
- Contests
- Community
- AI Assistant
- User Profile


## Tech Stack
